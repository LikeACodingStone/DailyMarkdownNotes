# Markdown Quick Reference

| Purpose | Markdown | Example |
|---|---|---|
| Heading 1 | `# text` | # text |
| Heading 2 | `## text` | ## text |
| Heading 3 | `### text` | ### text |
| Bold | `**text**` | **text** |
| Italic | `*text*` | *text* |
| Bold + Italic | `***text***` | ***text*** |
| Strikethrough | `~~text~~` | ~~text~~ |
| Inline code | `` `code` `` | `code` |
| Link | `[text](URL)` | [text](URL) |
| Image | `![alt](URL)` | Image |
| Unordered list | `- item` | - item |
| Ordered list | `1. item` | 1. item |
| Nested list | `  - item` | ↳ item |
| Task unchecked | `- [ ] task` | ☐ task |
| Task checked | `- [x] task` | ☑ task |
| Quote | `> text` | > text |
| Horizontal line | `---` | — |
| Code block | ```` ``` ```` | Code block |
| C++ code | ```` ```cpp ```` | C++ code |
| Bash code | ```` ```bash ```` | Bash code |
| Table | `\| A \| B \|` | Table |
| Table separator | `\|---\|---\|` | — |
| Left align | `:---` | Left |
| Center align | `:---:` | Center |
| Right align | `---:` | Right |
| Line break | `  ` | New line |
| HTML line break | `<br>` | New line |
| Escape character | `\*` | * |
| Footnote | `[^1]` | Footnote |
| Footnote text | `[^1]: text` | — |
| HTML comment | `<!-- text -->` | Hidden |
| Collapsible | `<details>...</details>` | Expandable |
